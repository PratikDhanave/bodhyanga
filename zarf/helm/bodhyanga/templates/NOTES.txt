Security Notes
--------------
- PodSecurity "restricted" profile is enforced (runAsNonRoot, readOnlyRootFilesystem,
  no privilege escalation, ALL capabilities dropped, seccompProfile: RuntimeDefault)
- NetworkPolicy is {{ if .Values.networkPolicy.enabled }}enabled (default-deny + allowlist){{ else }}DISABLED — enable for production!{{ end }}
- PHI: raw MRNs are never emitted to telemetry; case IDs are sha256[:8] hex only
- Audit log: appended to /var/lib/bodhyanga/audit.log inside the container (emptyDir at base)
  For HIPAA compliance, mount a WORM-capable PVC or forward via a log shipper

HIPAA / Compliance
------------------
This chart deploys a HIPAA-grade workload. Before going to production:
  1. Enable NetworkPolicy (networkPolicy.enabled=true)
  2. Use existingSecret with a compliant secret store (Vault, GCP Secret Manager, etc.)
  3. Replace the emptyDir audit volume with a WORM-capable PVC
  4. Enable Pod Disruption Budget (podDisruptionBudget.enabled=true) — ENABLED by default
  5. Review ingress TLS configuration
  6. Set up Workload Identity (serviceAccount.annotations) for cloud IAM
